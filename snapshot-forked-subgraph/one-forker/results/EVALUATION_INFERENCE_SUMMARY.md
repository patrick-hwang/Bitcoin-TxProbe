# Past Block Propagation Backward Inference Evaluation Summary

This document summarizes the performance and evaluation metrics of the backward network propagation inference engine executed on the fork dataset `fork_subgraph_height_102.json` across 1,000 nodes in the Bitcoin-TxProbe network topology.

## 1. Methodology & Theoretical Foundation

The backward inference engine determines the prior block propagation state at time $(t - \Delta)$ from the observed snapshot at time $t$ using the backward network propagation constraint rule:
$$\mathcal{U}_{\text{inferred}}(t - \Delta) = \mathcal{U}_t \cup \mathcal{N}(\mathcal{U}_t)$$
$$\mathcal{K}_{\text{inferred}}(t - \Delta) = \mathcal{V} \setminus \mathcal{U}_{\text{inferred}}(t - \Delta) = \{ w \in \mathcal{K}_t \mid \mathcal{N}[w] \subseteq \mathcal{K}_t \}$$

Where:
- $\mathcal{V}$ is the universe of nodes ($|\mathcal{V}| = 1000$).
- $\mathcal{U}_t$ is the set of uninformed/unknown nodes at time $t$.
- $\mathcal{N}(u)$ denotes the set of topological neighbors of node $u$.
- Ground truth is evaluated against exact block receipt timestamps recorded in `node_timings`.

## 3. Analysis by Block

### Block B1
- **Role**: Initial block generated by Node 0 at $t = 0\text{ ms}$.
- **Characteristics**: Widely propagated across the network, reaching saturation.
- **Inference Performance**:
  - High fidelity with mean Accuracy of $98.17\%$ and F1-Score of $90.90\%$.
  - Precision is particularly high ($94.23\%$), confirming that nodes inferred to know the block almost certainly did know it at $(t - \Delta)$.

### Block B2
- **Role**: Side-branch fork block submitted exclusively at Node 2 at $t = 100\text{ ms}$.
- **Characteristics**: It did not widely propagate before the network converged on B3.
- **Inference Performance**:
  - Steps 0–9 ($0\text{ ms} - 90\text{ ms}$): 0 nodes knew B2 in ground truth, and backward inference inferred 0 nodes. Result: 10 steps of perfect $1.0000$ Accuracy, Precision, Recall, and F1.
  - Steps 10–24 ($100\text{ ms} - 240\text{ ms}$): Only Node 2 received B2. Because all neighbors of Node 2 were uninformed, backward inference safely inferred that Node 2 could not have been known at $(t - 10\text{ ms})$.
  - Confusion Matrix: $TP = 0, FP = 0, TN = 999, FN = 1$. Accuracy is $99.90\%$ for all remaining steps.
  - Overall Mean Accuracy is $99.94\%$.

### Block B3
- **Role**: Main branch continuation block mined by Node 0 at $t = 100\text{ ms}$, resolving the fork.
- **Characteristics**: Rapidly cascaded across all 1,000 nodes.
- **Inference Performance**:
  - High precision ($98.63\%$) and recall ($96.22\%$), with an overall mean F1-Score of $96.47\%$.
  - Demonstrates strong predictive stability of the backward constraint algorithm even during aggressive network-wide propagation wavefronts.
